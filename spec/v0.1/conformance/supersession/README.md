# Supersession edge-case fixtures

V* status supersession (spec/02 "Status supersession (append-only
ledger)") encoded as fixture quartets. The `.ics` files are
generated deterministically by `cmd/fixtures-gen-supersession/`;
the `.canonical` and `.hash` siblings are regenerated by
`make fixtures-verify`. The `.notes.md` and this `README.md` are
hand-authored.

| File                  | Shape                                                   |
|-----------------------|---------------------------------------------------------|
| `linear.ics`          | Original VTODO + one supersession VJOURNAL → COMPLETED. |
| `multi_step.ics`      | Original + two supersessions: IN-PROCESS → COMPLETED.   |
| `cross_component.ics` | VTODO + VJOURNAL with RELATED-TO chain in one VCALENDAR.|
| `corrupt_mutated.ics` | VTODO with stale X-VSTAR-HASH (negative test).          |
| `effective_status_vevent.ics` | Turn VEVENT + one supersession VJOURNAL → CANCELLED, drawn from the VEVENT vocabulary. |

Files use **LF** line terminators on disk; the encoder emits CRLF
on output. Round-trip + integrity assertions live in
`supersession/fixtures_test.go`.

## Regenerating

From the repository root:

```
go -C go run ./cmd/fixtures-gen-supersession   # rewrite .ics
go -C go run ./cmd/fixtures-verify             # rewrite .canonical + .hash
```

`make fixtures-verify` (run as the CI parity step) reproduces only
the canonical/hash siblings — drift fails the PR. Regenerating the
.ics files is a deliberate act and is committed alongside any
change to spec/02 or the supersession package.
